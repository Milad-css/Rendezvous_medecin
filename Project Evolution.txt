// calender for the doctor 
Think of the calendar as a window. You decide what the user sees using 
the initialView and headerToolbar settings.

want a month u can use the ? Use dayGridMonth 

Want a Week with hours? Use timeGridWeek.

The Buttons: You can choose where to put the "Next" and "Previous" buttons : 

<FullCalendar
  initialView="dayGridMonth" 
  local = "fr"
  headerToolbar={{
    left: 'prev,next',   // Buttons on the left
    center: 'title',     // Month name in the middle
    right: 'timeGridWeek,dayGridMonth' // Switch buttons on the right
  }}
/>
